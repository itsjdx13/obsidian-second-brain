# Second Brain Workflow

## Capture → connect → act → review

1. Capture new questions in [[projects/RocoBroker/Catering/Open Questions/Research Inbox]] or a dated observation.
2. Preserve the original and create a source note from [[notes/Templates/Source Template]].
3. Extract one reusable idea using [[notes/Templates/Knowledge Template]], with page references.
4. Connect it to [[projects/RocoBroker/Catering/Supplier Map]] and the relevant project.
5. Record an actual choice in [[projects/RocoBroker/Catering/Decisions/Decision Log]]; never confuse a report preference with approval.
6. Recheck dependent notes when prices or terms change.

## Weekly review

- [ ] Process inbox items into sources, knowledge or actions.
- [ ] Check next actions in [[projects/RocoBroker/Catering/Selection/Catering Selection]].
- [ ] Resolve one item from [[projects/RocoBroker/Catering/Open Questions/Supplier Confirmation Checklist]].
- [ ] Mark expired/uncertain claims clearly; preserve their history.
- [ ] Run the vault validator.

No community plugins are required. Use Obsidian Search, backlinks and local graph to navigate the relationships.
