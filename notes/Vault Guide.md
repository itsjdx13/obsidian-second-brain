# Vault Guide

The vault has four visible top-level folders:

| Folder | What belongs here |
| --- | --- |
| `inbox/` | New material awaiting a decision about where it belongs. |
| `me/` | Personal context, work history, and daily or weekly review. |
| `notes/` | Reusable knowledge, references, templates, and historical material in `notes/Archive/`. |
| `projects/` | Work toward a specific result; keep its evidence and decisions with it. |

Use [[Home]] to navigate. Give substantial projects an overview note, such as [[projects/RocoBroker/Catering/Catering Overview|Catering]]. Keep original sources beside the relevant project or reference note. Link a reusable insight from a project into `notes/` only when it is useful beyond that project.

For a new capture, start at [[inbox/Capture Inbox]]. The [[me/Weekly Review|weekly review]] is the time to file or discard it. Shared templates live in [[notes/Index|notes]]. Historical workflow notes remain available under `notes/Archive/`.
