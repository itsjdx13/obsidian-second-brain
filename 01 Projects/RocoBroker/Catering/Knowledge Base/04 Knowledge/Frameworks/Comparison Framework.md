# Comparison Framework

A proposed evaluation schema, not a completed supplier ranking.

| Dimension | Evidence to collect |
| --- | --- |
| Total cost | Currency, per-person price, tax, packaging, delivery, minimum order |
| Menu fit | Rotation, portion specifications, dietary options, substitutions |
| Delivery fit | Location, time window, capacity, escalation process |
| Supplier capability | Documented experience and references; independently confirmed where needed |
| Commercial terms | Validity dates, payment, cancellation, price-change terms |
| Evidence quality | Source/page, quote date, outstanding confirmations |

## Use
Agree required constraints before assigning weights. Keep unknown values as “unknown,” not zero. Do not calculate rankings across incompatible scope or stale quotations.
