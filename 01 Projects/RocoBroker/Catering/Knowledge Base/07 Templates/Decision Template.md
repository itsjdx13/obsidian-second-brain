# Decision Template

Copy into `05 Decisions/` using the next available ADR number. Set type to `decision`, status to `proposed`, and replace this title. Add decision date and owner when known.

## Context
What problem needs a decision? What constraints apply?

## Options
List alternatives, including deferring the decision if evidence is insufficient.

## Decision
State the chosen option. Leave proposed until the authorized owner confirms.

## Evidence and rationale
Link reviewed sources and relevant concepts; include page references for factual claims.

## Consequences
Benefits, trade-offs, unknowns, and follow-up actions.

## Reconsideration trigger
What changed price, scope, date, or evidence requires a new decision?
