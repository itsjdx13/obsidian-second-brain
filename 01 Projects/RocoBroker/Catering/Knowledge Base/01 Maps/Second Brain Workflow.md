# Second Brain Workflow

## Capture → connect → act → review

1. Capture new questions in [[01 Projects/RocoBroker/Catering/Knowledge Base/06 Inbox/Research Inbox]] or a dated observation.
2. Preserve the original and create a source note from [[01 Projects/RocoBroker/Catering/Knowledge Base/07 Templates/Source Template]].
3. Extract one reusable idea using [[01 Projects/RocoBroker/Catering/Knowledge Base/07 Templates/Knowledge Template]], with page references.
4. Connect it to [[01 Projects/RocoBroker/Catering/Knowledge Base/01 Maps/Supplier Map]] and the relevant project.
5. Record an actual choice in [[01 Projects/RocoBroker/Catering/Knowledge Base/05 Decisions/Decision Log]]; never confuse a report preference with approval.
6. Recheck dependent notes when prices or terms change.
